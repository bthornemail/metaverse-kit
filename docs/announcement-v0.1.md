# Announcement v0.1

## Public Post Draft

We’re releasing **Metaverse Kit v0.1: a deterministic world demo**.

A world is packaged as a verifiable bundle you can hash, ship, replay, and audit.

The portal is projection-only. Canonical state is read-only.  
Proposal artifacts are explicit and portable.

This release demonstrates:

- deterministic replay
- integrity verification
- portable world bundles
- quarantined proposal export
- strict authority boundaries

Run the demo in under 60 seconds:

1. Download the bundle
2. Open the portal
3. Load the bundle
4. Explore and replay

This is infrastructure, not spectacle.

**Worlds you can verify.**
